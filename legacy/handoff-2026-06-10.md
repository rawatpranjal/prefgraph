## Landmines / gotchas
- **Editable install is NOT live for Python source.** maturin `pip install -e .` copies to
  site-packages, so .py edits need a rebuild (`python3.11 -m pip install -e . --no-build-isolation`)
  before pytest sees them. `docs/conf.py` reads from `../src`, so docs autodoc does NOT need a rebuild.
- **`gh pr checks --watch && gh pr merge` returns a misleading non-zero exit even when the merge
  succeeds or all checks pass.** Verify with `gh pr view <n> --json state` (MERGED), never the
  watcher exit code. Bit this session repeatedly.
- **Workflow worktrees persist when the agent committed** (`.claude/worktrees/wf_*`) and hold the
  branches, blocking branch deletion. Clean with `git worktree remove --force` then delete branches.
- **Run the FULL gate set before every push:** ruff check AND ruff format --check AND mypy AND pytest
  AND cargo test. `ruff check` alone misses format failures.
- Two uncommitted benchmark artifacts (`case_studies/benchmarks/...`) are pre-existing, the user's,
  left uncommitted on purpose. Stash them before any branch switch and restore after.
- HiGHS prints stderr noise (`HighsMipSolverData...`) during HM and VEI tests. Harmless, pipe `2>/dev/null`.
