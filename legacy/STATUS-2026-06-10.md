## Active chunks
`docs/chunks/` does not exist; this repo predates the chunk workflow. Open work tracked in `docs/roadmap.md` instead:

- **Exact-VEI tie-break** - parked on branch `feat/061-vei-exact`. The Python exact optimizer is correct, but an adversarial verifier showed the per-observation index is non-unique under ties, so Rust (HiGHS) and Python (scipy.milp) return different valid optima on discrete data (0.8 vs 0.9 on a 7-observation integer case). Deeper issue: the feedback-arc-set objective is not Varian's L1 norm, so the "exact" value is solver-dependent in both backends.

## TLDR
The big trust and correctness release is done.
