# Security Policy

## Supported versions

Security fixes are applied to the current 0.6.x release series. Older release lines do not receive security updates.

## Reporting a vulnerability

Please use GitHub's private security advisory feature to report vulnerabilities. Do not open a public issue for security-sensitive findings.

To file a private advisory, navigate to the Security tab of the repository and select "Report a vulnerability." We will acknowledge the report within a few business days and aim to publish a fix and advisory within 90 days, depending on severity and complexity.

If a finding turns out not to be a vulnerability, we will let you know promptly so you can disclose it publicly if you choose.
